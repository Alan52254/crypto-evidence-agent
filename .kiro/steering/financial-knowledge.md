# 金融指標解讀知識庫

本文件是 Agent 在 synthesise 階段解讀指標時的 ground truth 參考。
所有判斷必須符合這裡的邏輯框架，不得過度推論。

---

## 核心原則

- 指標只代表「條件」，不是結論；任何單一指標都不能單獨推出價格必然上漲或下跌。
- 加密貨幣市場的技術指標比傳統市場更容易失真（波動更高、24/7 交易、流動性不均、衍生品干擾）。
- 必須區分「趨勢市」與「盤整市」，同一指標在不同環境下含義可能相反。
- 任何極端值應視為「風險升高或狀態偏熱」，不是「立即反轉」的確定訊號。
- 多面向矛盾時，優先以更接近當前時間框架、且流動性更高的訊號為主；長周期決定大方向，短周期決定入場時機。

## 一、技術面指標

### RSI（相對強弱指標，14 週期）

RSI 是動量指標，衡量漲跌速度，不是純粹的反轉工具。

| 情境 | RSI > 70 的含義 | RSI < 30 的含義 |
|------|----------------|----------------|
| **趨勢市**（EMA 多頭排列 + 量能擴張） | 趨勢強勁，動能充沛 | 下跌趨勢強勁 |
| **盤整市**（價格在區間內震盪） | 接近區間上緣，反轉風險較高 | 接近區間下緣，反彈機會較高 |
| **趨勢末段**（遠離均線 + 量能衰退 + ATR 轉弱） | 過熱反轉風險升高 | 超跌反彈條件形成 |

正確用法：
- RSI > 70 / < 30 = 「動能偏極端」，**不是**「一定反轉」
- RSI 背離有參考價值，但不是高勝率獨立訊號；最有用的情境是「高時間框架 + 趨勢末段 + 量能同步轉弱」
- 加密貨幣比股票更容易長時間停留在高/低 RSI 狀態
- 時間框架可靠性：1d > 4h > 1h >> 15m（15m 極易被噪音與清算掃單干擾）

禁止的推論：
- 不得寫「RSI 超買，即將下跌」
- 不得單獨以 RSI 背離作為反轉結論

### EMA（指數移動平均線）

核心功能是辨識趨勢方向與動態支撐/壓力。

| EMA | 時間尺度 | 用途 |
|-----|---------|------|
| 9 | 短線動能 | 回撤後的快速修正判斷 |
| 21 | 短線到波段 | 常用趨勢線 |
| 50 | 中期趨勢 | 結構判斷分界 |
| 200 | 長期牛熊 | 宏觀趨勢濾網 |

正確用法：
- 多頭排列（EMA 9 > 21 > 50 > 200 且價格在上方）= 「趨勢結構偏多」，不是「一定續漲」
- 黃金交叉/死亡交叉 = 趨勢確認的**滯後**訊號，不是精準入場點
- 偏離幅度應用 ATR 或百分比標準化，不用固定點數
- BTC 與小幣的「過度偏離」定義不同，小幣波動更高

禁止的推論：
- 不得把黃金交叉寫成確定上漲訊號
- 不得用固定百分比定義所有幣種的「過度偏離」

### 成交量

核心邏輯：**價格變動若伴隨成交量確認，訊號較可信；若量價不一致，訊號較弱。**

| 組合 | 解讀 |
|------|------|
| 放量上漲 | 趨勢延續或突破可信度較高 |
| 縮量上漲 | 上攻動能不足，可能是反彈末段或缺乏跟進 |
| 放量下跌 | 拋壓或清算加劇 |
| 縮量下跌 | 可能接近賣壓耗盡，但需確認反轉結構 |

量價背離（價格創新高/低，但成交量未同步擴張）有警示價值，但在加密貨幣中容易被衍生品成交、跨交易所分流、洗量干擾，不能單獨當反轉證據。

異常判斷參考：
- 相對 20 日均量增加 50%：偏活躍
- 相對 20 日均量增加 100%+：顯著異常
- 以上為工程常用規則，不是普世統計定律

洗量（wash trading）可疑特徵：成交量高但價差不收斂、深度很薄、價格快速來回掃動。

### 其他技術指標（布林、MACD、ATR、斐波那契）

**布林通道**：
- 帶寬收窄 = 波動壓縮，後續可能出現較大波動，但方向無法單靠收窄判定
- %B > 1 或 < 0 = 價格相對通道位置極端，不代表必然反轉
- 重點不是「碰上軌就空」，而是觀察波動擠壓後是否出現方向性擴張

**MACD**：
- 滯後指標，交叉通常發生在行情已移動之後
- 更適合趨勢確認，不是精準抓底抓頂
- 柱狀圖反映動能增減速度

**ATR**：
- 波動率工具，不是方向工具
- ATR 上升 = 真實波動擴大（風險與滑點上升）
- ATR 低後急升 = 市場進入擴張期

**斐波那契回撤**：
- 學術上證據不穩定，更像市場自我實現的心理參考框架
- 可當「可能的支撐/壓力區」，不得寫成確定有效法則

## 二、籌碼面指標

### 資金費率（Funding Rate）

Binance USD-M 永續合約每 8 小時結算一次。資金費率 = 多空槓桿偏斜的成本。

| 狀態 | 含義 |
|------|------|
| 持續為正 | 多頭擁擠，做多需付費給空頭，市場偏樂觀 |
| 持續為負 | 空頭擁擠，做空成本較高，市場偏悲觀 |
| 極端高值 | 擁擠交易風險上升，**未必意味立即反轉** |

正確用法：
- 0.01% 常被視為相對中性，但不同幣種/時期的「正常值」不同
- 更合理的做法是看歷史分位數，不是硬編固定閾值
- 極端 funding + OI 上升 + 價格單邊延伸 = 趨勢可能仍在延續，但風險更高

禁止的推論：
- 不得寫「funding 過高，即將反轉下跌」
- 不得用固定閾值（如 0.05%）作為所有幣種的反轉判準

### 未平倉合約（Open Interest）

OI 上升 = 槓桿參與提升，方向判斷**必須結合價格變化**。

| 組合 | 解讀 |
|------|------|
| OI↑ + 價格↑ | 新增多單進場或空頭被迫平倉；若 funding 偏正，多頭擁擠風險升高 |
| OI↑ + 價格↓ | 新空單開倉或多頭承接失守；若伴隨放量，趨勢壓力增強 |
| OI↓ + 價格↓ | 多頭止損、去槓桿、連鎖清算 |
| OI↓ + 價格↑ | 空頭回補，倉位減少 |

- **變化率**比絕對值更有判斷價值（幣種規模差異大）
- 異常判斷：「超過 20 日均值 1 倍以上」可視為明顯異常，但需搭配價格與 funding

### 多空帳戶比（Long/Short Ratio）

Binance 提供兩種：
- **Global long/short account ratio**：所有交易者帳戶數比例（偏情緒）
- **Top trader long/short ratio**：前 20% 高保證金交易者（偏實際風險暴露）

正確用法：
- 可作為反向指標的參考，但不能機械化使用
- 散戶偏多**未必立刻跌**，趨勢可能仍在延續
- 有用的組合：極端偏斜 + 價格已處延長段 + funding/OI 同步過熱

### 買賣盤口（Order Book）

- 掛單量失衡不一定代表真支撐/壓力（spoofing、撤單常見）
- 加密貨幣盤口深度比傳統市場更容易瞬間蒸發
- 只能當短期流動性參考，不能當穩定預測工具
- spread 收窄 = 流動性好；spread 擴大 = 滑點風險升高

## 三、基本面事件

### 利多事件的時間尺度

| 事件類型 | 短期影響 | 中長期影響 |
|---------|---------|-----------|
| ETF 通過/申請 | 常在預期階段反映，公告可能 sell the news | 結構性正面（資金通道打開） |
| 減半 | 常提前數月反映 | 供給節奏變慢，長期偏多敘事 |
| 機構買入 | 取決於規模與市場流動性 | 需求結構性正面 |
| 網路升級 | 升級前反映→升級後震盪 | 若改善費用/擴容，長期正面 |
| 監管利好 | 若已被預期，公告波動可能不大 | 合規化長期正面 |

### 利空事件

| 事件類型 | 影響評估要點 |
|---------|-------------|
| Token unlock | 關鍵看「解鎖量 / 流通量」與「日均成交量能否吸收」 |
| 交易所安全事件 | 對整體市場短期風險偏好下降，對受害幣種衝擊更大 |
| 監管利空 | 涉及交易限制或資產定性時影響更持久 |
| 鏈上活動萎縮 | 中長期基本面轉弱信號，不是即日交易訊號 |

### Price In 判斷

判斷是否已 price in 的關鍵：
1. 事件前是否已出現異常上漲/下跌
2. OI 與 funding 是否先行擴張
3. 成交量是否在消息前就放大

若市場已在消息前出現持續單邊與高槓桿擁擠 → 公告後常見「利多出盡」或「利空出盡」。

「Buy the rumor, sell the news」不是鐵律，應改寫為：
**「若消息已被充分預期，實際公告後波動方向可能反轉或鈍化。」**

## 四、情緒面

### 新聞情緒的正確定位

- 新聞情緒 = 滯後與半領先並存（媒體追行情，但重大新聞也提前改變預期）
- 不應當成單獨買賣訊號，而是風險偏好、敘事強度與擁擠交易程度的輔助判斷
- 極端恐慌有時是買點，但前提是：已去槓桿 + 價格過度超跌 + 基本面沒同步惡化
- Fear & Greed Index 的逆勢策略在部分樣本中可能優於被動持有，但不可泛化成固定勝率

### 情緒解讀陷阱

- 牛市時利多報導過多，熊市時利空放大 → 情緒資料本身帶行情偏差
- 同一事件多家轉載 → 必須去重，不計為多個獨立事件
- 英文媒體通常更快更接近原始資訊，中文媒體可能經二次詮釋
- 付費新聞/軟文 → 降低權重；判斷依據：是否有原始數據、是否只做單邊敘事

## 五、跨面整合邏輯

### 訊號衝突的解讀框架

| 衝突組合 | 解讀 |
|---------|------|
| 技術面看多 + 基本面利空 | 短期結構仍強，但中期敘事承壓；若利空已 price in，技術面暫時占優 |
| 籌碼面過熱 + 情緒面恐慌 | 常見於清算後修復；槓桿已被清洗，短線可能有反彈條件 |
| 技術面看空 + 情緒面極度恐慌 | 若基本面無重大惡化，可能接近超跌；否則可能是下跌中繼 |

### 時間框架預測力

| 面向 | 短期預測力 | 中長期預測力 |
|------|-----------|-------------|
| 籌碼面（funding/OI/流動性） | 高 | 低 |
| 技術面（趨勢結構） | 中 | 中 |
| 情緒面 | 中（逆勢） | 低 |
| 基本面 | 低 | 高 |

### 多時間框架原則

- 日線定方向，4h 定時機
- 15m/1h 與日線相反時，不應逆著高時間框架硬做
- 先看大周期是否同向，再看小周期是否提供低風險切入點

### Agent 必須避免的錯誤推論

1. **把相關性當因果** — 「BTC 跌因為美股跌」只能說同步風險偏好變差，不代表直接因果
2. **過度外推近期趨勢** — 加密市場經常出現回撤、插針與清算造成的短期失真
3. **把單一極端值當確定訊號** — RSI 高 + funding 高 + OI 高 = 擁擠與風險升高，但不等於立即反轉
4. **忽略流動性條件** — 低流動性小幣在同樣指標下比 BTC 更容易被假訊號主導
5. **把媒體結論當系統結論** — 不得直接採信第三方分析師的觀點作為本系統判斷

## 六、幣種特性

以下以「相對 BTC」描述，避免硬編 beta 數字（beta 隨樣本期與市場狀態變動）。

### BTC
- 市場基準與主要風險資產錨定
- 驅動因素：宏觀流動性、ETF/機構資金、減半、美元流動性
- 波動特性：主流幣中相對最穩定，但仍屬高波動資產
- 流動性：深度最好，滑點最低

### ETH
- 與 BTC 高度相關，常被視為第二大系統性資產
- 驅動因素：L2 發展、網路升級、DeFi/NFT 活動、Gas 與質押經濟
- 波動特性：通常比 BTC 更波動，對敘事與生態活動更敏感
- 流動性：主流幣中深度高，但極端行情仍會快速擴大 spread

### SOL
- 與 BTC 相關性高，但對風險偏好更敏感
- 驅動因素：生態成長、TVL、鏈上活動、性能與應用採用
- 波動特性：一般比 BTC/ETH 更高波動
- 流動性：深度不如 BTC/ETH，急跌時滑點更明顯

### BNB
- 與 BTC 相關，但受交易所與 BNB Chain 事件影響更大
- 驅動因素：交易所生態、銷毀機制、鏈上活躍度、監管事件
- 波動特性：高於 BTC，低於更小市值山寨幣
- 流動性：高於多數山寨幣，但有事件驅動跳空風險

### XRP
- 與 BTC 相關，但常受監管敘事單獨驅動
- 驅動因素：監管進展、跨境支付敘事、交易所上架/下架
- 波動特性：高且容易受事件驅動急拉急跌
- 流動性：大型幣中尚可，但比 BTC 更容易出現短時失衡

## 七、Agent 報告的硬規則

以下規則在 synthesise 階段**必須**遵守：

1. 只描述「概率、風險、結構」，不要下「必漲/必跌」結論
2. RSI、MACD、EMA、布林、量價與籌碼指標都需要結合市場環境判讀；趨勢市與盤整市的解讀不同
3. funding、OI、多空比、盤口只能反映當下槓桿與流動性狀態，不能單獨預測方向
4. 任何「極端值」都應先判定為擁擠或風險升高，再檢查是否已 price in
5. 低流動性、小市值、短時間框架的訊號可信度較低，必須降低權重
6. 若資料不足或缺乏統計支持，明確標註「業界共識但缺乏嚴格回測」
7. 禁止保證式預測與買賣建議
8. 不得把媒體或第三方分析師的結論直接當成系統結論
