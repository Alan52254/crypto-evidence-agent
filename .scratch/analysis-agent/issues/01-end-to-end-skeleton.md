# 01 — 走通端到端骨架（假證據源 + 假模型）

**What to build:** 使用者可以對一個受涵蓋幣種發起分析請求，並拿到一份分析報告與一份推論軌跡。
此時所有證據來自固定的假證據源、所有模型呼叫來自腳本化的假模型 —— 但**流程是完整的**：
幣種閘門、蒐集、缺口檢查、報告組裝、引用檢核、軌跡輸出全部真實運作。

這是整個專案的曳光彈：它一次確立三個接縫的形狀、測試慣例、以及報告與軌跡的資料形狀。
後續每張票都是把某個假的部分換成真的。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 對受涵蓋幣種發起分析，回傳一份含方向、信心度、與掛載證據之判斷的報告
- [x] 同一次分析回合產出完整推論軌跡，每個節點記錄動作理由、輸入、產出證據識別碼、缺口變化
- [x] 非受涵蓋幣種在進入蒐集迴圈前被拒絕，回傳明確理由，不消耗任何預算
- [x] 未掛載證據識別碼的判斷被丟棄，不進報告，但該丟棄事件出現在軌跡中
- [x] **判斷以結構化物件生成並過濾，不得先生成 Markdown 散文再剪裁句子**
- [x] **證據源介面強制單次 I/O 逾時上限；掛起與失敗同義，皆回傳空集合**
- [x] 三個接縫（證據源、分析回合、模型供應者）以介面定義，依賴由外部注入
- [x] 整組測試不碰網路、不呼叫真實模型即可通過
- [x] 版本依 Spec 0001 鎖定，`mcp` 寫死上界不得升 2.x
