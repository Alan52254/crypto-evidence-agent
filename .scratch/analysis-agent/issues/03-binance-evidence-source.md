# 03 — 真實證據源：Binance 公開 REST（技術面與籌碼面）

**What to build:** 分析報告中出現由真實市場數據算出的技術面與籌碼面證據 ——
均線、RSI、成交量變化、買賣盤結構等。每一項證據都指向它的原始數值序列與擷取時間，
使用者可以追回「這個 RSI 是用哪段 K 線算出來的」。

Binance 公開端點無需金鑰、以 IP 計 weight，是本專案的輪詢主力。

**Blocked by:** 01

**Status:** done

- [x] 已實作現貨 K 線來源，產出技術面證據（SMA、RSI、成交量變化）
- [x] 已實作合約公開端點來源，產出籌碼面證據（資金費率、未平倉合約、多空帳戶比）
