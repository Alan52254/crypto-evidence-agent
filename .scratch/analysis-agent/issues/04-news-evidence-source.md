# 04 — 真實證據源：新聞 RSS（基本面與情緒面）

**What to build:** 分析報告中出現引用真實新聞的判斷，讀者點擊證據標記可以看到
原文片段、文章 URL 與發布時間。同一篇文章可同時產出基本面證據（發生了什麼事）
與情緒面證據（文本的傾向），因為**證據面與資料源是正交的**。

RSS 無金鑰、無額度限制、天然帶時間戳與原文連結，是本專案性價比最高的證據源。
