# 05 — 真實模型供應者：推理層與勞務層

**What to build:** 分析回合改由真實模型驅動。推理層負責決定下一步蒐集什麼、
以及從證據推出判斷；勞務層負責高頻低階工作（單則片段的情緒打分、摘要、實體抽取）。
開發者可以只改設定就替換任一層的模型，分析邏輯完全不動。

**Status:** done

- [x] 腳本化假模型仍可完全取代真實模型，既有測試不需修改即通過
