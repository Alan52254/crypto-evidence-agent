**What to build:** 蒐集不再是固定順序，而是由模型依據**當前證據缺口**自行決定
下一步呼叫哪些工具、要不要再挖一輪。評審可以在推論軌跡上看到模型**改變主意**的痕跡：
發現某一面證據不足 → 決定補抓 → 缺口縮小。

外層狀態圖仍是固定的（規劃 → 蒐集 → 缺口檢查 → 組裝），保證一定收斂。
