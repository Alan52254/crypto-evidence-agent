# 07 — 報告組裝、引用檢核與信心度

**What to build:** 使用者拿到的報告開頭就有方向與信心度，接著是四個證據面各自的傾向，
然後是每一句都掛載證據識別碼的判斷。當技術面與情緒面互相矛盾時，
報告明確告知信心度低；當只蒐到單一面的證據時，報告顯示「證據不足」而非高信心度。

**Blocked by:** 06

**Status:** done（驗收條件於 ticket 01 + 05 實作時一併達成，已逐條對照程式碼與測試）

- [x] 每個證據面能獨立產出方向傾向
- [x] 信心度由**證據面之間的一致程度**計算（見 ADR 0002），為確定性 Function 工具
- [x] **「證據不足」是與「低信心度」不同的第三態**，兩者在報告中可分辨
- [x] **推理層以結構化物件陣列輸出判斷（判斷文字 + 證據識別碼 + 證據面），
      引用檢核對陣列過濾，過濾後才渲染 Markdown。不得事後剪裁散文**
- [x] 引用檢核丟棄所有未掛載有效證據識別碼的判斷；丟棄事件記入軌跡
- [x] 信心度的輸入是**歸併後的證據**（ADR 0002 證據獨立性）
- [x] 報告輸出為結構化結論物件（純函數產出），使後續加入跨幣比較層無需重構
- [x] 報告含明確聲明其非投資建議
- [x] 信心度本身可溯源：讀者可看出是哪幾面的分歧造成低信心度
