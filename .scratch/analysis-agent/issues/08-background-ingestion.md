# 08 — 背景 ingestion 與向量檢索

**What to build:** 系統在收到分析請求之前就已持續蒐集五個受涵蓋幣種的新聞與市場數據。
分析回合因此能引用**數週前**的相關報導作為脈絡，而不只是當下 15 分鐘抓得到的東西。
報告中出現「本次事件與 X 月的某則報導呼應」這類需要歷史深度的判斷。

⚠️ 此票需**賽前提前上線並持續運行**，否則向量庫是空的，檢索無物可撈。
排程上必須早於 Demo 至少一到兩週。
