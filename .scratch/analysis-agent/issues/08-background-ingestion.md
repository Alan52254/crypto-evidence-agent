# 08 — 背景 ingestion 與向量檢索

**What to build:** 系統在收到分析請求之前就已持續蒐集五個受涵蓋幣種的新聞與市場數據。
分析回合因此能引用**數週前**的相關報導作為脈絡，而不只是當下 15 分鐘抓得到的東西。
報告中出現「本次事件與 X 月的某則報導呼應」這類需要歷史深度的判斷。

⚠️ 此票需**賽前提前上線並持續運行**，否則向量庫是空的，檢索無物可撈。
排程上必須早於 Demo 至少一到兩週。

**Blocked by:** 02, 03, 04

**Status:** ready-for-agent

- [ ] 排程輪詢持續將新聞與市場數據寫入 pgvector（最笨但可靠的做法，不引入串流基礎設施）
- [ ] 輪詢頻率不得超出各資料源額度；CoinGecko 僅作補充欄位，不作輪詢主力
- [ ] 向量檢索作為 MCP 工具暴露，回傳的每則結果都帶完整來源片段
- [ ] 重複內容在寫入前去重，避免同一則新聞在報告中被引用多次
- [ ] 分析回合可同時使用歷史檢索結果與即時證據，兩者在報告中可區分
- [ ] 向量庫為空時分析回合仍能正常完成
