# 09 — 推論軌跡視覺化前端

**What to build:** 評審打開一個網頁，輸入分析回合識別碼，看到這次推理的完整過程：
時間軸上每個決策點、模型當時為何選擇這個動作、產出了哪些證據、
證據缺口如何隨之改變、以及最終報告中的每一句判斷連回哪些證據。

被丟棄的無證據判斷也要顯示（標記為已丟棄），讓評審看到引用檢核確實在運作。

這是評審實際會盯著看的畫面，計分權重高。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 依回合識別碼呈現完整推論軌跡，時間軸與樹狀兩種視圖
- [ ] 每個軌跡節點顯示：動作理由、輸入摘要、產出證據、缺口變化
- [ ] **證據 → 判斷的連線可視化** —— 這是「點對點之間為什麼」的具體兌現
- [ ] 點擊任一證據可展開原始來源片段、出處 URL、擷取時間
- [ ] 顯示被引用檢核丟棄的判斷並標明原因
- [ ] 時間軸顯示 15 分鐘預算的消耗分布
- [ ] 分析進行中可看到即時進度與已蒐集證據數
