# HoyaBit 系統架構圖 — 完整資料流與功能描述

> 從使用者輸入 Prompt → LLM 推論 → 資料蒐集 → 報告生成的完整流程

---

## 1. 端對端資料流（主流程）

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        使用者介面 (Frontend)                              │
│  Next.js 15 + React + Tailwind                                          │
│                                                                          │
│  ┌──────────────┐  ┌──────────────┐  ┌─────────────────────────────┐   │
│  │ 幣種選擇器   │  │ 問題輸入框   │  │ 即時行情 Marquee (WebSocket)│   │
│  │ BTC/ETH/SOL  │  │ "BTC短線     │  │ BTC $62,980 | ETH $3,412   │   │
│  │ BNB/XRP      │  │  方向研判"   │  │                             │   │
│  └──────┬───────┘  └──────┬───────┘  └─────────────────────────────┘   │
│         │                  │                                             │
│         └────────┬─────────┘                                             │
│                  ▼                                                        │
│  POST /api/v1/analyse {asset: "BTC", question: "..."}                   │
│                  │                                                        │
│                  ▼                                                        │
│  GET /api/v1/stream_trace?run_id=xxx  ←── SSE 即時串流（每15秒心跳）    │
│                  │                                                        │
│  ┌───────────────▼──────────────────────────────────────────────────┐   │
│  │ ReAct Trace 面板（右側）     │  報告渲染區（中間）                │   │
│  │ • ASSET_GATE ✓               │  • Executive Summary              │   │
│  │ • GAP_CHECK → 缺口分析       │  • 技術圖表 (SVG K線/RSI/走勢)    │   │
│  │ • PLAN → 工具選擇理由        │  • Claims (fact/inference/concl)  │   │
│  │ • GATHER → 13項證據          │  • 反方論點 + 風險聲明            │   │
│  │ • SYNTHESISE → 8則判斷       │  • 信心度: 66%                    │   │
│  │ • REPORT → 最終方向          │  • 限制聲明                       │   │
│  └──────────────────────────────┴───────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────┘
```

## 2. 後端處理流程（Python Starlette Server）

```
POST /api/v1/analyse
        │
        ▼
┌───────────────────────────────────────────────────────────────────┐
│  Step 1: 幣種閘門 (gate_asset)                                    │
│  ─────────────────────────────────                                │
│  • 白名單檢查: BTC/ETH/SOL/BNB/XRP                               │
│  • 不在名單 → 立即拒絕，不進入推論                                │
│  • 確定性程式判斷，不交給模型                                      │
└────────────────────────┬──────────────────────────────────────────┘
                         │ ✓ 通過
                         ▼
┌───────────────────────────────────────────────────────────────────┐
│  Step 2: 題型分類 + 核心資料偵測                                   │
│  ─────────────────────────────────                                │
│  • classify_question() → market_summary / hypothesis / technical  │
│  • detect_core_data_demands() → 關鍵字比對（確定性）              │
│    ▸ "交易所儲備" → UNAVAILABLE                                   │
│    ▸ "巨鯨轉移" → UNAVAILABLE                                    │
│    ▸ "美股" → PARTIAL                                             │
│  • derive_requirement() → 需要哪些面、最低來源數                  │
└────────────────────────┬──────────────────────────────────────────┘
                         │
                         ▼
┌───────────────────────────────────────────────────────────────────┐
│  Step 3: 預取 (Prefetch) — 同時發 7 個 API                        │
│  ─────────────────────────────────                                │
│                                                                    │
│  ┌─────────────┐ ┌─────────────┐ ┌──────────────┐               │
│  │ binance_spot│ │ coingecko   │ │ fred_macro   │               │
│  │ K線+指標    │ │ 市值+漲跌   │ │ 利率+M2+CPI │               │
│  └─────────────┘ └─────────────┘ └──────────────┘               │
│  ┌─────────────┐ ┌─────────────┐ ┌──────────────┐               │
│  │ defillama   │ │ fear_greed  │ │ candlestick  │               │
│  │ TVL         │ │ FGI 指數    │ │ SVG 圖表     │               │
│  └─────────────┘ └─────────────┘ └──────────────┘               │
│  ┌──────────────────┐                                             │
│  │ binance_derivati │  ← 資金費率 + OI + 多空比                   │
│  └──────────────────┘                                             │
│                                                                    │
│  產出: ~15-20 項 Evidence（技術+籌碼+基本+情緒四面）              │
└────────────────────────┬──────────────────────────────────────────┘
                         │
                         ▼
┌───────────────────────────────────────────────────────────────────┐
│  Step 4: 缺口檢查 (evidence_gap)                                  │
│  ─────────────────────────────────                                │
│  • 檢查四個面是否都有證據                                          │
│  • 檢查獨立來源數 ≥ 2                                             │
│  • 檢查正反方向是否都有                                            │
│  • sentiment 只有 FGI 不算（需要真正的新聞）                       │
│                                                                    │
│  缺口未關閉 → 進入 ReAct 蒐集迴圈                                │
│  缺口已關閉 → 跳到 Step 6                                        │
└────────────────────────┬──────────────────────────────────────────┘
                         │ 有缺口
                         ▼
┌───────────────────────────────────────────────────────────────────┐
│  Step 5: ReAct 蒐集迴圈（最多 6 輪）                              │
│  ─────────────────────────────────────                            │
│                                                                    │
│  ┌─────────────────────────────────────────────────────────────┐ │
│  │  5a. LLM Plan (model.plan)                                   │ │
│  │  ──────────────────────────                                   │ │
│  │  輸入: 當前證據缺口 + 已蒐集證據 + 可用工具                  │ │
│  │  輸出: 決定呼叫哪些工具 + 用什麼參數                         │ │
│  │                                                               │ │
│  │  範例輸出:                                                    │ │
│  │  "sentiment 面只有 FGI，需補新聞情緒"                         │ │
│  │  → crypto_news(hours=24, limit=8)                             │ │
│  │  → extended_news(hours=24, limit=8)                           │ │
│  └──────────────────────────┬──────────────────────────────────┘ │
│                              │                                     │
│  ┌──────────────────────────▼──────────────────────────────────┐ │
│  │  5b. 執行工具 (並行)                                         │ │
│  │  ─────────────────────                                        │ │
│  │  • 呼叫外部 API                                              │ │
│  │  • 新聞 → LLM label() 打情緒分數                             │ │
│  │  • 產出新 Evidence 項目                                       │ │
│  └──────────────────────────┬──────────────────────────────────┘ │
│                              │                                     │
│  ┌──────────────────────────▼──────────────────────────────────┐ │
│  │  5c. 缺口再檢查                                              │ │
│  │  ─────────────────                                            │ │
│  │  • 所有必補缺口關閉 → 跳出迴圈                               │ │
│  │  • 仍有缺口 → 回到 5a                                        │ │
│  │  • 預算用罄 → 強制跳出，以現有證據繼續                       │ │
│  └──────────────────────────────────────────────────────────────┘ │
└────────────────────────┬──────────────────────────────────────────┘
                         │
                         ▼
```
